RANCH MANAGER — запуск на Windows

1. Распакуйте все файлы в папку RanchManager на рабочем столе.
2. Переименуйте .env.example в .env (включите отображение расширений в Проводнике).
3. Откройте .env в Блокноте и замените ВСТАВЬТЕ_СЮДА_ТОКЕН_БОТА на секретный токен из Discord Developer Portal. Никому его не отправляйте.
4. В адресной строке Проводника внутри папки RanchManager введите cmd и нажмите Enter.
5. Установите зависимости: py -m pip install -r requirements.txt
6. Запустите: py bot.py
7. Дождитесь сообщения «Бот подключён».
8. Создайте в Discord два текстовых канала, например запасы-ранчо и история-запасов.
9. В Discord администратором выполните /запустить_запасы и выберите оба канала.

Команды администратора: /норма, /остаток, /добавить_продукт.
Доступ к кнопкам: роли «с РанЧо» и «!Человек с метлой!», а также администраторы.
Важно: текущая база SQLite локальная. Для 24/7 понадобится хостинг с постоянным диском и перенос файла ranch.db. Не запускайте одновременно две копии бота с разными базами.
